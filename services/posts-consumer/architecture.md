# Сервис TgPostsConsumers


- Динамическая архитектура:
   - Базовые консьюмеры для существующих групп (инициализация при старте)
   - Реактивное создание новых консьюмеров через:
        - Прослушивание топика tg_channels_diff
        - Валидацию через кэш (исключение дубликатов)

- Шардированная обработка:
    - Каждый консьюмер привязан к уникальному топику tg_posts_{id}
    - Автономная обработка сообщений в рамках своей группы
    - Общая стратегия записи: batch-вставки с конфликт-менеджментом

- Кэш-синхронизация:
    - Двухуровневая система:
        - Персистентный слой (синхронизация с БД при инициализации)
        - Оперативный слой (обновление через события из tg_channels_diff)
